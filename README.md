# Задание 6. Реализация подсистемы управления файлами сигнатур (Опционально)


1. Реализовать API загрузки сигнатур на основе файлов.
   
2. Реализовать эндпоинт загрузки и рассчета сигнатур по одному файлу. В БД нужно сохранять данные сигнатуры, а исходный файл должен отправляться в файловое хранилище (MinIO).
   
3. Реализовать эндпоинт получения списка pre-signed URL по списку идентификаторов сигнатур.
   
4. Ограничить доступ к данному API ролью администратора.
   
5. Поднять и настроить контейнер MinIO для сохранения файлов и получения pre-signed URL.
   
6. Все bucket-ы с файлами должны быть приватными.
   
7. Для доступа с сервера создать отдельные access key/secret key в MinIO, не использовать root.
