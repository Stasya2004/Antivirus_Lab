# Задание 1. Подготовка репозитория

1. Создать Git репозиторий для серверной части проекта.

2. Перенести в новый репозиторий из прошлого проекта: аутентификацию (JWT access/refresh), авторизацию (ролевая модель, правила доступа), шифрование (HTTPS), подключение к БД PostgreSQL (или иной, используемой в работе реляционной БД).

3. Перенести переменные и секреты с репозитория РБПО, либо создать новые.

4. Перенести pipeline из прошлого проекта в новый, с шагами test и build.

5. Изучить теорию по UML-диаграммам, ознакомиться с типами диаграмм, их значениями.

6. Ознакомиться с теорией по ER-диаграммам.
